산업분야 분류기

회사 소개글을 입력하면, 처음부터 설계한 자모 단위 토크나이저 + 소형 GPT(1,180만 파라미터)가 위키백과 한국어 텍스트로 사전학습한 뒤 미세조정되어 산업분야를 예측합니다. 외부 사전학습 모델(BERT, GPT 등)은 전혀 쓰지 않았습니다.

예측 결과

    이 모델에 대해

    • 사전학습(언어모델링) → 미세조정(산업분야 분류) 2단계로 직접 학습
    • 같은 구조를 사전학습 없이 학습시킨 비교군 대비 검증 정확도 34.9% vs 23.4% (21개 업종, 무작위 추측 기준선 4.8%) — 사전학습 효과를 수치로 확인
    • 업종 라벨은 한국어 위키백과 카테고리 체계를 그대로 썼습니다 — 회사 하나가 업종 여러 개에 걸치는 경우 라벨이 임의로 하나만 배정될 수 있고, 학습 데이터가 업종당 평균 수십 개뿐이라 예측이 자주 틀릴 수 있습니다. 포트폴리오용 실험 프로젝트이니 참고용으로만 봐주세요.
